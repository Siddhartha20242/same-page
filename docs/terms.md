## What Same Page is
Same Page is a Forge app for Jira Cloud and Confluence Cloud. It compares a work item with the Confluence pages linked to it, shows contradictions it can prove with fixed rules, and can propose a fix.

## Preview notice
Same Page is early-stage software. It has not been used by a real team yet, and its test results come from examples written by its authors. Expect rough edges and changes.

## A person decides
The app proposes changes. It edits a page only when a person clicks Apply. The edit is saved as a normal page version and can be reverted from page history. Review tasks and comments are created only when a person clicks or when the pin check reports a regression.

## Limits of the checks
A proposed fix is checked to be minimal: it changes only a version reference and clears the flagged contradiction. That does not prove the new text is correct. You are responsible for reviewing every change before you apply it and for the content of your pages and work items.

The app does not promise to find every contradiction. It can miss some and flag others that are not real. Use it as a second pair of eyes, not as your only control.

The optional pre-ship gate can refuse a Jira transition. If it errors or times out it allows the transition. Administrators can remove it from the workflow at any time.
